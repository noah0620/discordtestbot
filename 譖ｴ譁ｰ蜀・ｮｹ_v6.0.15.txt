Discord MultiBot v6.0.15

・/era search が複数表示される問題を修正
  - /era はグローバル登録の1個だけを使用
  - v6.0.14以前に作成されたサーバー限定 /era をBOT起動時に自動削除

・音楽再生を修正
  - youtube-dl-exec依存を廃止
  - SNSダウンロードと同じ Python yt-dlp を使用
  - Windows: python -m yt_dlp
  - Linux/macOS: python3 -m yt_dlp
  - cookies.txt を自動検出
  - 再生直前に最新の音声ストリームURLを取得

Windowsでは事前に python -m pip install -U yt-dlp を実行してください。
